Visualiseur de Collecte de Données

Un outil pédagogique pour comprendre les mécanismes de collecte de données personnelles sur le web : cookies, pixels de suivi, et politiques de confidentialité.

Interface UI - Fonctionnalités à venir
🍪 Gestion des Cookies

Explorez différents niveaux de consentement aux cookies et visualisez leur impact sur la collecte de données (simulation UI).

📊 Pixel de Suivi

Découvrez comment fonctionnent les pixels de suivi invisibles et quelles données ils peuvent collecter (démo visuelle).

📜 Politiques de Confidentialité

Analysez et comprenez les politiques de confidentialité avec un outil de détection de catégories sensibles (interface placeholder).

🎵 Cas d'Usage : TikTok

Étude de cas sur la collecte de données par TikTok : scénarios, données observables, et implications (contenu éducatif statique).

▶️ Cas d'Usage : YouTube

Analyse des mécanismes de collecte de données sur YouTube et leur impact sur la vie privée (contenu éducatif statique).

À propos de ce projet

Ce visualiseur est un projet universitaire conçu pour sensibiliser aux pratiques de collecte de données en ligne. L'interface actuelle présente la structure et le design final du site.

Note : Cette version contient uniquement l'interface utilisateur. Les fonctionnalités de collecte, d'analyse et de visualisation seront implémentées dans les prochaines étapes du projet.
