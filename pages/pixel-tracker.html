Comprendre le pixel de suivi

Définition rapide

Un pixel tracker est généralement une image invisible (souvent 1×1) chargée automatiquement. Ce simple chargement déclenche une requête réseau qui permet d’observer un contexte de visite (page consultée, moment, environnement technique, etc.).

Pourquoi c’est “dangereux”

  • Invisible : aucun clic n’est nécessaire.
  • Corrélable : une série d’événements permet de profiler des habitudes.
  • Traçable : répétition dans le temps, ré-identification via identifiants/paramètres.
  • Transversal : dans le web, dans les emails, dans les pubs (mesure & conversion).

Intérêt pour un site / mail / attaquant

  • Mesure : savoir qu’une page a été vue / qu’un email a été ouvert.
  • Analyse : comprendre parcours, engagement (temps, scroll, clics).
  • Marketing : attribution (UTM), conversion, retargeting (conceptuellement).
  • Renseignement : récolter métadonnées techniques (UA, écran, timezone, etc.).

Comment s’en protéger

  • Bloqueurs (uBlock Origin), protections anti-tracking.
  • Bloquer cookies tiers / limiter referrer, protections du navigateur.
  • En email : afficher les images désactivé par défaut, mode texte.
  • Navigation privée (limite certains stockages), isoler les sites (containers).
